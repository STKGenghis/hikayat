# Hikayat

Hikayat is an independent redesign and actively developed implementation of an AI-safety learning experience built around interactive storytelling.

## Origin

Hikayat — both the name and the concept of using interactive storytelling to make AI-safety risks concrete — was originated by Saima Tariq Khan, who also wrote the original 18 scenarios.

## Project history

This repository contains the new design and independent implementation. It is separate from the React interface produced for the Dubai hackathon prototype.

The historical prototype, its GPLv3-licensed source code, and its original implementation credits are preserved at [github.com/STKGenghis/hikayat-dunetech](https://github.com/STKGenghis/hikayat-dunetech).
